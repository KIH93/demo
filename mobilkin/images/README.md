# Фото для галереи

Сейчас блок "Галерея" в index.html скрыт (атрибут hidden у section#gallery). После получения фото от владельца положить их сюда, раскомментировать теги img и убрать hidden.

Нужные фото (JPG или WebP, около 1200x900, до 200 КБ каждое):

- facade.jpg - фасад и вход (вывеска "Мобилкин")
- hall.jpg - интерьер зала
- workplace.jpg - рабочее место мастера
- showcase.jpg - витрина с аксессуарами

Использовать только фото владельца, не брать картинки с 2GIS и стоков.
