# New Game, компьютерный клуб (Видное): демо сайта

Демо: https://kih93.github.io/demo/newgame/

Статика без сборки: `index.html`, `style.css`, `script.js`, `favicon.svg`. Внешние зависимости только шрифты Google Fonts (Rajdhani, Manrope). Все пути относительные, папку можно целиком перенести на домен клиента.

Источники данных: карточка 2GIS, Telegram-канал @newgamevidnoe (проверено 20.10.2026).

## Демо закрыто от поисковиков

В `index.html` стоят `<meta name="robots" content="noindex, nofollow, noarchive, nosnippet">` и `<meta name="googlebot" content="noindex, nofollow">`, sitemap, canonical и разметки нет.
При запуске на домене клиента: удалить эти строки, убрать строку "Демонстрационная версия сайта" в подвале, добавить sitemap.xml, canonical и разметку LocalBusiness.
