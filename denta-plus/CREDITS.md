# Источники изображений и шрифтов: демо "Дента Плюс"

## Изображения
Фотографии на демо не используются. Все изображения нарисованы для демо в коде страницы:
- зубная карта на первом экране (script.js, блок "зубная карта"): схематичные SVG-зубы, сделаны для демо;
- иконки в блоке "Что вас беспокоит", иконки мессенджеров и интерфейса: SVG в index.html;
- схема проезда в разделе "Контакты" (SVG): условная, не настоящая карта местности. Ссылка ведёт на карточку Яндекс Карт https://yandex.ru/maps/org/denta_plyus/210972350024/;
- знак в шапке и favicon.svg: упрощённый знак для демо, не фирменный логотип клиники. Оригинальный логотип: https://dentakzn.ru/wp-content/uploads/2022/05/cropped-logo.png (в демо не используется, взяты только ориентиры по цвету).

Вместо фото врачей стоят заглушки с инициалами и подписью "фото будет добавлено". Реальные фото клиники и сотрудников можно добавить только с подтверждением прав.
