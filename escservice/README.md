# ESC Service: демо-концепт сайта

Демо нового сайта для сервисного центра ESC Service (Казань, ул. Вишневского, 59).
Подготовил Ильдар. Это не официальный сайт компании, страницы закрыты от индексации (`noindex`).

Ссылка: https://kih93.github.io/demo/escservice/

## Что внутри

- `index.html`: главная (услуги, подборщик "Что сломалось?", как работаем, цены, отзывы, FAQ, контакты).
- `remont-fotoapparatov.html`: пример страницы услуги под поисковый запрос.
- `js/config.js`: телефоны, мессенджеры, график и цифры. Правки вносятся здесь.
- `js/main.js`, `css/style.css`, `img/`: скрипты, стили, иконки.

Сборка не нужна: статический HTML, CSS и JS. Открыть можно через любой локальный сервер, например `python -m http.server` в этой папке.
