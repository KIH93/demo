# Источники изображений и шрифтов: демо Султан

## Изображения

Фотографии в демо не используются. Все графические элементы сделаны вручную в коде:

- первый экран: мозаика-сетка плиток, геометрический орнамент (восьмиконечная звезда из двух квадратов), медальон, линейный рисунок ножниц, бритвы и расчёски: SVG и CSS, оригинальная вёрстка для демо;
- иллюстрация в блоке "Детям" (кресло, ребёнок в накидке, ножницы): SVG, нарисована для демо;
- монограммы в карточках мастеров: заглушки без фото людей;
- иконки (звезда, адрес, телефон, часы, коляска, вход без ступеней, доступность): упрощённые SVG, нарисованы для демо;
- логотип и фавикон: условные, сделаны для демо, не являются логотипом компании.

Реальные фото барбершопа из 2ГИС не используются.
