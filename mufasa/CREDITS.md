# Муфаса: источники изображений и шрифтов

## Изображения

Фотографии в демо не используются. Все графические элементы сделаны вручную в коде:

- первый экран: анимированная абстрактная "грива" из золотых линий на canvas, генерируется скриптом, оригинальная работа для демо, не изображает какого-либо персонажа;
- блок "Отец + Сын": абстрактные силуэты без лиц, оригинальный SVG;
- галерея (кресло, бритва, укладка, ножницы, гребень, зеркало): оригинальные SVG-иллюстрации, не реальные фото барбершопа;
- схема карты в контактах: условная SVG-иллюстрация, ведёт на карточку 2ГИС;
- карточки мастеров: заглушки с буквами, без фото людей;
- иконки (Telegram, WhatsApp, MAX, телефон и др.): упрощённые SVG, нарисованы для демо;
- логотип и favicon: условные, сделаны для демо, не являются логотипом компании.

Реальные фото барбершопа из 2ГИС и Яндекс Карт не использовались.
