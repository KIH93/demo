# Источники изображений и шрифтов: демо FixStyle lounge

## Изображения

Фотографии в демо не используются. Все графические элементы сделаны вручную в коде:

- первый экран: иллюстрация лаунж-зоны (лампы, круглые зеркала, кресла, столик с чаем, растения) и анимация вертикальных жалюзи: оригинальный SVG и CSS;
- бегущая лента "ритуала визита": CSS, оригинальная вёрстка;
- блок SPA для головы: анимированный круг "вдох / выдох", CSS;
- галерея: слайдер "до / после" и плитки (чай, инструменты, интерьер): оригинальные SVG-иллюстрации, не реальные работы салона;
- карточки мастеров: заглушки с буквами, без фото людей;
- иконки (WhatsApp, Telegram, VK, телефон, чашка и др.): упрощённые SVG, нарисованы для демо;
- фавикон: оригинальный SVG.

Реальные фото салона, мастеров и интерьера не используются. Логотип условный, текстовый.
