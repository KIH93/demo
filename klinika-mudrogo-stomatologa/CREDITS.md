# Источники изображений, шрифтов и данных: демо "Клиника мудрого стоматолога"

## Изображения
Фотографии на демо не используются. Все изображения сделаны для демо в коде страницы:
- отрывной календарь "Совет дня" на первом экране (HTML и CSS, листы перелистываются анимацией): оригинальное оформление;
- зубик с щёткой в блоке "Детская стоматология" (SVG в index.html): нарисован для демо;
- иконки услуг (SVG в index.html): нарисованы для демо;
- заглушки вместо фото врачей (инициалы на фоне, CSS): фото врачей нужно получить у клиники с согласием на публикацию;
- логотип и favicon (favicon.svg): временный знак, не фирменный логотип клиники.

Фото клиники из 2ГИС, Яндекс Карт, VK и Instagram не копировались.
