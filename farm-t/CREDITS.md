# Источники изображений: демо Фарм-т

Все изображения на демо оригинальные, нарисованы в SVG и CSS специально для этого демо. Стоковые фото не использовались.

| Изображение | Где на сайте | Источник |
|---|---|---|
| Линия ЭКГ, лёгкие со сканером, пробирки, домик с маршрутом, маршрут от метро | Первый экран | Оригинальная SVG/CSS-графика, index.html, style.css |
| Иллюстрация дневного стационара (кушетка, капельница) | Раздел "Услуги" | Оригинальная SVG-иллюстрация, index.html |
| Схема проезда | Контакты | Условная SVG-схема, не настоящая карта |
| Логотип-заглушка, favicon | Шапка, вкладка браузера | Оригинальная SVG-графика, favicon.svg |
| Иконки | Весь сайт | Оригинальные SVG-иконки, index.html |

Реальные фото центра, врачей и пациентов не использовались. Аватары врачей заменены буквами, имена и стаж условные.

Шрифты: Manrope и Golos Text (Google Fonts, SIL Open Font License 1.1).
