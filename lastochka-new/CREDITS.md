# Источники: Ласточка NEW (демо)

Вторая версия демо, оформлена по дизайн-системе скилла UI UX Pro Max (стиль Motion-Driven, сторителлинг по главам). Сторонние фотографии не используются. Фото студии и работ мастеров из VK и 2ГИС не брались.

## Изображения
- Знак ласточки (логотип, favicon, птица на первом экране, бегущая строка, заглушки мастеров): оригинальный SVG-силуэт, нарисован для этого демо, код в index.html и favicon.svg. Логотип студии не перерисовывался.
- Портфолио (ласточка, полумесяц, змея и кинжал, роза, ветка, мотылёк, сердце): оригинальные SVG-иллюстрации, созданы для этого демо, код в script.js. Это примеры, не реальные работы студии.
