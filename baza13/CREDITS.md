# Источники изображений и шрифтов: демо База13

## Изображения

Фотографии в демо не используются. Все графические элементы сделаны вручную в коде:

- первый экран: стена из 13 металлических ячеек, дверца 13 открывается: CSS, оригинальная вёрстка;
- собака с виляющим хвостом: оригинальный SVG, нарисован для демо;
- пропуск со штрихкодом, бейджи мастеров: CSS, оригинальная вёрстка;
- карточки мастеров: заглушки с буквами, без фото людей;
- иконки (звезда, часы, метка, телефон, WhatsApp, VK): упрощённые SVG, нарисованы для демо;
- фавикон: оригинальный SVG.

Реальные фото компании, мастеров и интерьера не используются. Логотип и цвета условные.
