# Источники изображений и шрифтов: демо Best Barbers

## Изображения

Фотографии в демо не используются. Все графические элементы сделаны вручную в коде:

- доска с наборными буквами на первом экране: CSS и HTML, оригинальная вёрстка;
- иллюстрация ножниц в блоке прайса: оригинальный SVG;
- подарочный сертификат: CSS, оригинальная вёрстка;
- карточки мастеров: заглушки с буквами, без фото людей;
- иконки (телефон, WhatsApp, Telegram, VK, YouTube и др.): упрощённые SVG, нарисованы для демо.

Реальные фото компании, мастеров и интерьера не используются. Логотип условный.
