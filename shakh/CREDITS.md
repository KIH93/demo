# Источники изображений и шрифтов: демо Shakh

## Изображения

Фотографии в демо не используются. Все графические элементы сделаны вручную в коде:

- первый экран: бильярдный стол, вид сверху (сукно, борта, лузы, шары, две подвесные лампы): CSS, оригинальная вёрстка, анимация удара написана для демо;
- счётные бусины в блоке цифр: CSS, оригинальная вёрстка;
- "шары" с буквами в карточках мастеров: заглушки без фото людей;
- иконки (Wi-Fi, собака, пандус, коляска, WhatsApp, телефон и др.): упрощённые SVG, нарисованы для демо;
- логотип и фавикон: условные, сделаны для демо, не являются логотипом компании.

Реальные фото барбершопа, мастеров, интерьера и граффити (Dikidi, 2ГИС, Яндекс Карты, текущий сайт) не используются.
