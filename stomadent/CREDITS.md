# Источники изображений, шрифтов и данных: демо "СтомаДент"

## Изображения
Фотографии на демо не используются. Все изображения сделаны для демо в коде страницы:
- гирлянда ценников на первом экране (HTML и CSS): оригинальная иллюстрация;
- иконки (SVG в index.html): нарисованы для демо;
- логотип и favicon (favicon.svg): предложение для демо, не фирменный знак клиники. Оригинальный логотип нужно получить у клиники.

Вместо фото врачей стоят заглушки с инициалами и подписью "фото будет добавлено". Реальные фото клиники и врачей можно добавить только с подтверждением прав. Изображения лицензий с сайта клиники не копировались.

## Данные
- Цены, врачи, гарантия, адрес, телефоны, почта: сайт клиники https://stoma-dent.org/
- Рейтинг 4,9 (177 оценок, 163 отзыва), бесплатная консультация, снимок 500 руб.: карточка 2ГИС https://go.2gis.com/Y7EWy
- Условные данные с пометкой "пример": акция, график, стаж врачей, скидки и сертификаты, отзывы, часть цен пародонтологии и неотложной помощи, ИНН, ОГРН, номер лицензии.
